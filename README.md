# LifeSim
Тестовое задание симулятор "жизни" Дж. Конвея

Стек: TypeScript / React / Mobx / Vite

Правила:

1. Бесконечная плоскость, разделенная на клетки;
2. У клетки два состояния - живая или мертвая;
3. У клетки 8 соседей;
4. Если у клетки 2-3 соседа, то клетка живая, иначе умирает;
5. Если клетка мертва и имеет 3 соседа, то становится живой;
6. Симуляция прекращается при:
  -  отсутствии живых клеток на поле;
  -  отсутствии динамики состояний;
  -  повторном состоянии на более ранних шагах.
